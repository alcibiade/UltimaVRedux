# Reports and contributions

Thank you for helping improve Ultima V Redux. **Please open an issue first.** The
maintainer currently owns implementation and prefers reports and discussion over
unsolicited code pull requests.

## Report a problem

Use the [issue forms](https://github.com/bradhannah/UltimaVRedux/issues/new/choose)
and include:

- Game version or commit, when known.
- Operating system, architecture, and Go version for build/install problems.
- What you expected and what actually happened.
- Steps to reproduce, including relevant game conditions.
- Useful error text or public documentation/reference identifiers.
- After a crash, the `crash.log` described in [files and folders](docs/INSTALL.md#files-and-folders).

Gameplay observations, public manuals, and other public references are welcome.
Explain the scenario that supports a claim; a correction need not arrive as code.

Please do not attach original game assets or copyrighted source material. Remove
personal information from diagnostics. If a save or another file is necessary for
reproduction, describe what it contains and discuss a suitable way to provide it
with the maintainer first.

## Suggestions and documentation corrections

Describe the problem or confusing behavior, its context, and the improvement you
would like. If you know a relevant behavior/reference ID, include it; knowing one
is not required to submit a useful report.

## Code changes

Discuss scope in an issue before preparing a PR. The maintainer may implement the
change directly or agree on a contribution. An accepted proposal is not a promise
to accept an independently prepared implementation.

Preserve attribution and license notices, including those accompanying bundled
fonts, media, and fixtures. Changes must follow the repository's
[architecture](docs/ARCHITECTURE_GUIDELINES.md), [coding conventions](docs/CODING_CONVENTIONS.md),
and [testing policy](docs/TESTING.md). The [development guide](docs/DEVELOPMENT_GUIDE.md)
describes tools and local validation. Humans review and merge PRs.

## Current availability

Prerelease builds are on the [releases page](https://github.com/bradhannah/UltimaVRedux/releases), and `main` installs the
moving development line. The [installation guide](docs/INSTALL.md) explains
installation, updates, local builds and [platform status](docs/INSTALL.md#platform-status).
