# Ultima V Redux

This repository is preparing its first source release. It currently contains
documentation and issue forms; the application has not yet been staged.

- Read [README.md](README.md), [installation guidance](docs/INSTALL.md), and
  [contribution policy](CONTRIBUTING.md).
- Describe actual availability honestly. Do not claim install, build, test, or
  platform acceptance for an application that is not present here.
- Use dedicated branches and preserve unrelated work.
- Keep documentation useful on its own. Explain gameplay with precise behavioral
  descriptions, data-format information, and pseudocode where appropriate.
- Original game assets are user-supplied. Preserve required notices and do not
  add original game files or source excerpts.
- The maintainer prefers issue reports and owns implementation. Use explicit
  repository identities for GitHub operations.
- Do not commit, push, create PRs, or alter repository visibility without explicit
  authorization. Humans merge PRs.

Application-specific architecture and validation guidance will accompany the
reviewed source. Do not add placeholder gameplay or fictitious test results to
make the planned installation command appear available.
